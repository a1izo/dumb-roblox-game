Fixes to the three flaws found after the v38/v37 import ([[maps-agency38-campus37-import]], [[surface-detail-phase-12]]).

- **Pipe steel:** new flat material `PipeSteel` (matlib FLAT, Metal 128 132 140, reflectance 0.08, no texture, 0 MP) is `kit.pipe_run`'s default instead of the tiled `Steel` scan. Seen in Roblox: the pipe is a smooth bar (the Edit view shows it plain pale grey: flat materials are only dressed by SceneBuilder at run time, so the real colour is not seen there). Campus uses it too (its two labs and hall); Campus megapixels unchanged 160.35 (the old 0.07 overrun), triangles 161,941.
- **Dark dado:** every Agency dado (PlasterDark, WoodPanel) is 2.8 high and scuffs sit at 0.65..2.65, so they were dark on dark. `kit.wear(dado=True)` now drops the scuff kind from that face before the shuffle (tape marks and switch plates sit above the dado), so the 0 to 3 seeded marks and the no-same-kind-side-by-side rule hold. The dado-only offset constant is gone.
- **Stain (the hard one):** Roblox treats this sheet's alpha almost as a cut-off near 0.5 in the Edit view (a 0.3-0.6 soft fan showed as a small hard brown dot; the old hairline showed, the halo never did). Soft alpha cannot be seen there. Final `_stain` (wear.py): a wide ragged patch drawn above the cut-off, a stippled fringe of single grit dots, colour warm grey (118 110 100). Reads as a damp patch on the copy room's tan wall; on the interview hall's blue-grey wall it reads tan, closer to mud than damp; edges are only slightly broken, not soft. Iterations v40 (0.62 alpha: dot), v41 (ragged, brown blob), v42 (94 91 88: dark smudge on tan), v43 (final). If soft really matters, give the stain a real engine-supported look (a mesh with Transparency, or a colour matched per wall).
- **Versions:** the digest in a venue's init.luau does not hash texture bytes, so a texture-only change keeps the version: reset the `-- mesh digest:` line by hand to force a bump (done 39 to 43). Maps Agency 43 (asset 123998526363250), Maps Campus 38 (asset 98174404449168). Intermediate uploads that are NOT in use: Agency v39 101607533068961, v40 135938090575578, v41 131396797984452, v42 92512228307378.
- **Import:** from the main checkout's art/export (an upload from a worktree path is refused by the permission classifier), PATCH to universe 10767766818 OK, markers `DeathsGambitMapsAgency_Version_43` / `DeathsGambitMapsCampus_Version_38`, PivotTo(old pivot) gave O (75.19, 699.64, 88.40) and (75.19, 1745.73, 88.40), one copy each in Workspace, ServerStorage clean, place saved v668 (not published).
- **Pictures with this Studio:** it ran minimised (window at -32000), and screen_capture then returns a flat dark frame. `ShowWindow(handle, 4)` (restore, no activate) gives real 3D; `ShowWindow(handle, 7)` puts it back.
