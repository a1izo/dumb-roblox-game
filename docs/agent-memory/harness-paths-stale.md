`docs/handoff/harness/` is the second-minimised-Studio harness ([[studio-no-screen]]), copied into the repo from another
developer's scratch folder. Found 2026-11-14, reading it to plan a watch of the Luau match scenes (nothing was run):

- `run.ps1` builds with `docs/handoff/tools/rojo.exe`; that folder does not exist in the repo. Rojo here is
  `~/.aftman/bin/rojo`. Its Python is Blender 5.2's bundled one (that path does exist).
- `make_project.py` takes the repo from the `AUDIT_REPO` environment variable, and its default is a path on the other
  developer's machine. Set `AUDIT_REPO` to your worktree first.
- `emote.project.json` is generated by `make_project.py` (not in the repo); the `vfxtex` and `vfxmesh` folders it adds
  are optional.
- The probes (`Shots`, `Scenes`, `Gallery`, `Deaths`) play the Blender shots and the death scenes straight through
  `ShotPlayer` and the gallery. There is no probe for the Luau match scenes (verdict, arrest, outro, Oculus deal): those
  need a running match, so the harness would have to `fillBots` and `startMatch` through the `Debug` event first, in a
  place built without the imports (bare ground for a map).

**How to apply:** for a quick look at a match scene, the Studio MCP in the owner's place once Studio is out of Play
([[studio-mcp]]) is far less work than adapting the harness; use the harness for batch runs that need no imports. Related:
[[studio-cutscene-testing]].
