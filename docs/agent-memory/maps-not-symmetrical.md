Map layouts must never be (close to) symmetrical. They need variation, narrow pathways, random
turns and elevation changes, while still being a good, readable layout.

**Why:** the user explicitly and strongly rejected mirrored or plus-grid layouts ("not 100% symmetrical").
**How to apply:** use off-centre junctions, bending avenues, unequal quarters, alleys with dog-legs and dead ends,
hills, terraces, sunken paths and raised decks. The map checker should flag high mirror overlap. Relates to [[map-remake-project]].
